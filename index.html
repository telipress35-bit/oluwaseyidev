Engineering highlights

Where money is involved, details matter

A few production problems I've solved. This is the kind of thinking you get when you hire me.

RELIABILITY

Self‑healing electricity payments

Built electricityReconciler.js, which sweeps pending transactions every 2 minutes and refunds safely using SELECT FOR UPDATE SKIP LOCKED, so no customer is refunded twice.

SECURITY

15‑point security audit

Cryptographic OTPs with crypto.randomInt, a pinned JWT algorithm, login enumeration protection, PIN and OTP brute‑force lockout, and mandatory admin MFA.

AUTH

Refresh tokens across 4 apps

Cut access tokens from 7 days to 30 minutes, with 401‑intercept‑retry interceptors and single‑flight guards in the backend, web, mobile and admin apps.

INTEGRATION

Kuda Business API, end to end

Token caching with retry, four DB migrations and a provider that fits the multi‑provider design. Confirmed with a live ₦100 SportyBet funding.

CORRECTNESS

Pending is not failed

Fixed timeouts being reported as failures across bill pages, and taught the system that VTpass 000 without a token means pending, not success.

INFRA

Email that actually arrives

Traced lost emails to SMTP being blocked on Railway and moved delivery to the Brevo HTTP API.
